## 🌟 Curriculum & Course Overview

This repository archives coursework, laboratory practicals, course projects, and research papers completed during the **Master of Computer Applications (MCA)** program at the **School of Computer Engineering, Manipal Institute of Technology (MIT), Manipal Academy of Higher Education (MAHE)**.

The coursework spans four core academic pillars:
1. **Object-Oriented Programming (`MCA 4142`)**: In-depth C++ systems programming, operator overloading, virtual inheritance hierarchies resolving diamond ambiguities, runtime polymorphism, and persistent binary object serialization.
2. **Database Management Systems (`MCA 4141`)**: Relational database architecture, integrity constraints, 39 complex analytical queries, Oracle PL/SQL programming (cursors, triggers, stored procedures, functions), and a full-scale **Mobile Manufacturing System** mini-project.
3. **Web Technology (`MCA 4143`)**: Client-side layouts (HTML5, responsive CSS3 Grid/Flexbox, physics animations), interactive DOM/Canvas scripts, asynchronous AJAX/JSON real-time search, server-side PHP with MySQL CRUD operations, and a full-stack **Campus Event & Volunteer Management System** course project.
4. **Research Methodology & Technical Communication (RMTC)**: Theoretical foundations of academic inquiry (hypothesis testing, sampling, research design) alongside a specialized research report on **Rigid 3D–2D Medical Image Registration using Deep Learning**.

## 🚀 Execution & Setup Guidelines

### 1. Compiling and Running C++ Programs
Ensure GCC/MinGW (`g++`) is installed and available in your environment path:
```bash
# Navigate to the target weekly directory
cd c++/week6

# Compile the C++ source file
g++ w6ex2.cpp -o w6ex2.exe

# Execute the generated binary
./w6ex2.exe
```

### 2. Executing Oracle SQL & PL/SQL Scripts
Ensure Oracle Database (XE or Enterprise) and SQL*Plus are configured:
```sql
-- Connect to SQL*Plus
sqlplus username/password@XE

-- Enable server output for PL/SQL execution
SET SERVEROUTPUT ON;

-- Execute a specific lab script
@c:/MCA/dbms/week7/lab7a1.sql
```

### 3. Running Web Technology Applications
- **Static Pages (HTML5 / CSS3 / JavaScript — Weeks 1 to 9):**  
  Open any `.html` file directly in any modern web browser or serve via VS Code *Live Server*.
- **Dynamic Server-Side Pages (PHP & MySQL — Weeks 10, 11 & Course Project):**  
  1. Start the Apache and MySQL services via **XAMPP** or **WAMP**.
  2. Map or link the `wt/` directory into your server's web root (`htdocs/wt`).
  3. Import the corresponding database schema (e.g., `library` database for Week 11).
  4. Access via browser at: `http://localhost/wt/wt/week11/index.php`.
