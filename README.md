## 🌟 Overview

This repository serves as an academic archive of coursework completed in the **Master of Computer Applications (MCA)** curriculum. It captures progressive hands-on learning across four core disciplines:
1. **Object-Oriented Programming**: Core language mechanics, memory management, operator overloading, inheritance hierarchies, runtime polymorphism, and binary file stream persistence in C++.
2. **Database Management Systems**: Relational database modeling (ER diagrams), schema design, integrity constraints, complex SQL queries, and advanced Oracle PL/SQL programming (cursors, triggers, stored procedures, and functions), along with a relational mini-project.
3. **Web Technology**: Progressive web development covering semantic HTML5, CSS3 responsive grid/flexbox and physics keyframe animations, JavaScript DOM & Canvas manipulation, AJAX/JSON asynchronous communication, and server-side PHP with MySQL database connectivity.
4. **Research Methodology & Technical Communication**: Formal technical writing, methodology design, literature review, and architectural modeling for medical image registration using deep learning.

## 🚀 Execution & Usage Guidelines

### 1. Compiling and Running C++ Programs
Ensure GCC/MinGW is installed and available in your system path:
```bash
# Navigate to the target week directory
cd c++/week6

# Compile the C++ source file
g++ w6ex2.cpp -o w6ex2.exe

# Execute the compiled binary
./w6ex2.exe
```

### 2. Executing Oracle SQL & PL/SQL Scripts
Ensure Oracle Database (XE or Enterprise) and SQL*Plus are installed:
```sql
-- Connect to SQL*Plus
sqlplus username/password@XE

-- Enable console output for PL/SQL blocks
SET SERVEROUTPUT ON;

-- Execute a specific SQL / PL*SQL script
@c:/MCA/dbms/week7/lab7a1.sql
```

### 3. Launching Web Technology Practicals
- **Static Pages (HTML / CSS / JavaScript — Weeks 1 to 9):**  
  Open any `.html` file directly in any modern browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge), or serve them using a local development server such as VS Code *Live Server*.
- **Dynamic Server-Side Pages (PHP & MySQL — Weeks 10 & 11):**  
  1. Install and start Apache and MySQL using **XAMPP** or **WAMP**.
  2. Place or link the `wt/wt` directory inside the web root (e.g., `htdocs/wt`).
  3. For Week 11 MySQL CRUD, import or create the `library` database and `books` table as configured in `week11/index.php`.
  4. Access via browser at: `http://localhost/wt/week11/index.php`.
